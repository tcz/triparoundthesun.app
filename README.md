# triparoundthesun.app

Static website for the Trip Around the Sun iOS app, served by GitHub Pages.

- `index.html` – landing page with App Store link
- `privacy/index.html` – privacy policy (keep in sync with `PrivacyPolicyView` in the iOS app)
- `.well-known/apple-app-site-association` – Universal Links for `/card/*` (postcard deep links)
- `CNAME` – custom domain for GitHub Pages
